ALESIA – Under the hood

  1. In-house modelling
    A set of analytical and quasi-analytical models for superconducting magnets, built directly into ALESIA, for example Biot–Savart field and quench modelling. This allows them to access the material and project databases directly.
  2. Data analysis tools
    An additional layer of tools to facilitate data analysis for optimisation.
  3. Learning surrogate
    Surrogate modelling based on the simulation data.
  4. Multi-parametric optimisers
    Based on evolutionary computation and active learning, including genetic algorithms (GA), differential evolution (DE), particle swarm optimisation (PSO), covariance matrix adaptation evolution strategy (CMA-ES), Bayesian optimisation and deep neural networks (DNN).
  5. Interface with physics software
    Integrates external physics simulation codes to export input data from ALESIA to the simulation code and to import the resulting output data back into the ALESIA project database.
  6. Project database
    Stores inputs, outputs and simulation scripts. Facilitates data analysis by surrogate models.
  7. Material database
    Stores material properties and superconductor fits.
  8. Project manager
    Launches simulations and supports their parallel execution on Windows, macOS, Linux and HPC clusters (Slurm).

For each run

  • A design score is assigned
    • $f(y)=\sum_i w_i\,(y_i-t_i)^2$
    • Targets $t$ and weights $w$
  • Goal: find a global minimum
    • Without being trapped by local minima
    • Taking into account discontinuities
    • Achieved by optimisers

Search heuristic optimisers

Random (benchmark)

Points drawn uniformly at random

No real convergence

Genetic algorithm (GA)

Selection of the best, crossover and mutation

Slow convergence: requires evaluating large populations over multiple generations

Differential evolution (DE)

New individuals from weighted differences between others

Easy to use: few hyperparameters (F, CR, population size)

Particle swarm (PSO)

Particles drawn to their own best and to the swarm’s best position

Easy to use: low number of hyperparameters

CMA-ES

Evolution strategy: the Gaussian search distribution (dashed ellipse) adapts its size and orientation

Self-adapting: no step size to tune

Bayesian optimisation (BO)

Gaussian-process surrogate; new points maximise the expected improvement

Better convergence: reduces the amount of data required

Deep neural network (DNN)

Active learning: network refitted at each iteration; new points are the best predicted

Weaknesses: training overhead, risk of overfitting

Evolutionary computation

  • GA, DE, PSO, CMA-ES, ant colony…
  • Easy to use: low number of hyperparameters
  • Slow convergence: large populations over many generations

Machine learning (active learning)

  • Surrogate model (GP, DNN) refitted at each iteration
  • Better convergence: reduces the amount of data required
  • Weaknesses: training overhead, overfitting

Both: handle non-differentiable or discontinuous functions and can escape local minima, but do not guarantee the global optimum
